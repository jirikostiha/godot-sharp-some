# GodotSharpSome API Reference

Welcome to the **Godot Sharp Some** API Reference.

`GodotSharpSome.Drawing2D` provides extension methods and helper structures for 2D drawing in Godot applications.

## Namespaces

- **`GodotSharpSome.Drawing2D`**: CanvasItem drawing extension methods (`CanvasItemExtension`), multiline vertex builder (`Multiline`), line styling types (`SolidLine`, `DottedLine`, `DashedLine`, `DashDottedLine`), line options (`LineType`, `LineVoptions`), and 2D vector helpers (`Vector2DExtension`).
